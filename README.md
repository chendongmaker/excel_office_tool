# Excel批处理助手

一个面向日常办公的 Windows 桌面小工具，覆盖 Excel 批处理、数据清洗、数据对比和图表生成。

## 当前 MVP 功能

- 批量读取 `.xlsx`、`.xls`、`.xlsm`、`.csv`
- 上传文件后自动解析表头、字段类型和字段覆盖率
- 通用字段选择器：全选、取消全选、反选、搜索字段、显示字段来源文件
- Excel 纵向合并，并自动添加“来源文件”
- 按指定字段匹配合并多个表
- 常用清洗规则：删除空行、删除重复行、文本去空格、列名修改、删除列、空值填充、日期和数字标准化，并按用户勾选字段执行
- 两个 Excel 按主键对比，支持单独选择对比字段，导出“新增 / 删除 / 修改”三个工作表
- 基于字段生成柱状图、折线图、饼图 PNG
- 本地历史任务记录和页面操作日志
